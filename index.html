step 04 · two ways

同一套数学，两种书写习惯

下面两份代码训练出的参数几乎逐位相同。区别不在能力，而在「谁替你保存中间变量」：命令式框架把状态挂在对象上，函数式框架把状态当参数传。

PyTorch · 状态挂在张量上

imperative
import torch, torch.nn.functional as F

torch.manual_seed(42)
W = torch.empty(2, 2).uniform_(-1, 1).requires_grad_()
b = torch.zeros(2, requires_grad=True)
v = torch.empty(2, 1).uniform_(-1, 1).requires_grad_()
c = torch.zeros(1, requires_grad=True)
opt = torch.optim.Adam([W, b, v, c], lr=0.06)

for step in range(260):
    h     = torch.sigmoid(x @ W + b)                  # 4×2 隐藏层
    logit = h @ v + c                                 # 4×1
    loss  = F.binary_cross_entropy_with_logits(logit, y)
    opt.zero_grad()
    loss.backward()        # 梯度写进 .grad
    opt.step()             # 按 .grad 更新参数
↳
可以随时停下看 .grad、替换其中一行、或把 Adam 换成 SGD——状态都在对象里，改哪个都可控。

JAX · 状态当参数传

functional
import jax, jax.numpy as jnp, optax

def forward(p, x):
    h = jax.nn.sigmoid(x @ p["W"] + p["b"])
    return h @ p["v"] + p["c"], h

def loss_fn(p, x, y):
    logit, _ = forward(p, x)
    return jnp.mean(optax.sigmoid_binary_cross_entropy(logit, y))

grad_fn = jax.jit(jax.value_and_grad(loss_fn))   # 纯函数可 jit
opt, state = optax.adam(0.06), optax.adam(0.06).init(params)

for step in range(260):
    loss, grads = grad_fn(params, x, y)   # 无副作用
    updates, state = opt.update(grads, state, params)
    params = optax.apply_updates(params, updates)
↳
没有可变的 .grad，梯度只是返回值；同一份 loss_fn 可以 jit、可以 vmap、可以在 TPU 上重排。

step 06 · inside one iteration

一轮里到底发生了什么

四步、九个参数、一次全批量。把它拆开看，Adam 就不再是黑箱。

线性投影

z = x·W + b

四个样本各得到两个隐藏预激活值，输入平面第一次被两条直线切开。

压进概率

h = σ(z)

Sigmoid 把每个预激活折到 (0,1)，非线性在这里出现，XOR 才有可能。

读数与损失

logit = h·v + c

再线性组合一次，用带 logits 的交叉熵衡量与目标的距离。

Adam 更新

θ ← θ − lr·m̂/(√v̂+ε)

一阶、二阶动量一起用，学习率 0.06，九个参数同步移动。
